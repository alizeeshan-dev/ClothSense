# Personal-photo qualitative demo

Place approximately 20 personally sourced `.jpg`, `.jpeg`, or `.png` clothing
photographs in this directory. They are ignored by Git. Optionally copy
`labels.example.csv` to `labels.csv` and record an expected Fashion-MNIST class.

Run from the repository root:

```powershell
python -m scripts.process_demo_images
```

This is a qualitative domain-mismatch demonstration, not a benchmark dataset.
